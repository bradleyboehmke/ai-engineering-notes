Base model vs assistant

From Lesson 4. Same loop, different weights: where assistant behaviour comes from.

The pipeline

documents (trillions of tokens) ──pretraining──▶ base model       continues any document
conversations (SFT)            ──┐
preference pairs (RLHF / DPO)  ──┴post-training▶ assistant        answers, then ends its turn

both:  tokens → model → next token → append → repeat   (lesson 2's loop, unchanged)

Terms

Base modelThe result of pretraining. Predicts the next token of a document, so it continues text rather than replying.HF
Post-trainingTraining after pretraining that shapes behaviour: usually SFT, then a preference stage
SFTSupervised fine-tuning on example conversations (SmolLM2-Instruct: ~485K)HF
RLHF / DPOPreference tuning toward replies people rated betterInstructGPT
AssistantAlso called an instruct or chat model. A post-trained model that answers in a conversation format
Chat templateRenders a list of messages into one token string with role markers. Specific to each model family.HF
Generation promptThe empty assistant turn at the end of the template (add_generation_prompt=True) that the model fills
End-of-turn tokenCloses each turn (<|im_end|>, <|end|>). An assistant stops by choosing it.

Formats seen so far

ChatML (SmolLM2, Qwen)   <|im_start|>user\n…<|im_end|>\n<|im_start|>assistant\n
Harmony (OpenAI gpt-oss)  <|start|>user<|message|>…<|end|><|start|>assistant
Hosted APIs               you send messages; the provider handles the format

Consequences for builders

Wrong or no templateNo error, just worse output. Always use apply_chat_template on open-weight models.
Hidden tokensThe template adds tokens, and sometimes a default system prompt, that you didn't write but still pay for
Base modelsSteer them with a document whose next line is the answer (few-shot), plus a stop sequence
Knowledge vs behaviourFacts mostly come from pretraining or the context. Post-training shapes format, stopping, tone, and refusals.
Model upgradesNew post-training can change behaviour even when the prompt is the same. Rerun your evals.
