# Starting point: strong ML, light LLM mechanics

Brad is a technical data scientist who teaches ML theory, model evaluation, and Python at university level and understands neural networks. His use of LLMs is high level: he uses skills and knows basic prompting, but his understanding of how LLMs are built and run under the hood is light, and how usage translates into cost is loose.

**Implications**: skip ML fundamentals and use them as anchors (e.g. softmax → sampling, distribution shift → knowledge cutoff). Start from tokens and the generation loop. Don't assume any LLM vocabulary yet. No terms are demonstrated, so the first lessons sit at "new vocabulary", not "correcting misconceptions".
