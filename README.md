# AI Engineering Notes

An open-ended path into AI Engineering, learned and documented in public by
[Brad Boehmke](https://github.com/bradleyboehmke).

I'm a data scientist and team lead moving into AI Engineering. This repo is
both my learning system and its output: a website of standalone topics, a
linked dictionary of terms, prototypes, and the tools I build along the way.
Every topic is written through two lenses: doing the engineering, and leading
the people who do it.

## What's here

| Folder | Contents | Published |
|---|---|---|
| `topics/` | Concepts explained with runnable code | Yes |
| `dictionary/` | One term per file, cross-linked | Yes |
| `essays/` | Synthesis and opinion | Yes |
| `prototypes/` | Side projects with write-ups | Yes |
| `tools/` | Skills and scheduled tasks built for this repo | Yes |
| `learning/` | `/teach` workspaces, one per theme | No |
| `notes/` | Raw notes per source | No |
| `inbox/` | Radar proposals awaiting screening | No |
| `docs/` | Architecture decisions and agent configuration | No |

Folders are created as content arrives.

## Start here

- `MISSION.md`: why this exists, where I'm starting from, and my rules
- `ROADMAP.md`: the stages, themes, and the tool built at each stage

Open questions and planned work live in
[GitHub Issues](https://github.com/bradleyboehmke/ai-engineering-notes/issues).

## How it works

Curate, screen, learn, distill, connect. A scheduled radar proposes reading; I
screen it against the roadmap; skills help me learn and test my understanding;
I draft pages and dictionary terms in my own words, and an agent challenges and
sharpens them; links tie them into a network.
